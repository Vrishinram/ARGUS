# GitHub Profile Polish Checklist (Maintainer)

Use this checklist to keep ARGUS positioned as a flagship project.

- [ ] Add ARGUS to the top of your profile README with a one-line value proposition:
      "ARGUS: autonomous LLM security triage + policy enforcement gateway."
- [ ] Pin only 4–6 production-ready repositories; unpin tutorial/experimental repos.
- [ ] Keep ARGUS release cadence visible via tags and release notes.
- [ ] Keep ARGUS quickstart and demo assets current so profile traffic converts quickly.
